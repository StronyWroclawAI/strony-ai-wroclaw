# Pliki źródłowe logo

- `plansza-oryginalna.png` — dostarczona plansza koncepcyjna (wariant 3). Numer wariantu i tło planszy nie są częścią logo.
- `znak-raster-przezroczysty.png` — wycięty znak SA, przezroczyste tło (raster).
- `logo-pelne-raster-przezroczyste.png` — znak + napis + hasło, przezroczyste tło (raster).

Pliki SVG w `public/assets/img/` (`logo-znak*.svg`, `logo-pelne*.svg`, `favicon.svg`) powstały przez **automatyczną wektoryzację** (potrace) powyższego rastra. To robocze odwzorowanie, nie oryginalny plik wektorowy. Jeśli otrzymasz źródłowe SVG od projektanta lub z narzędzia, w którym powstało logo, podmień pliki, zachowując nazwy.
